## Secret Blog / Memory Vault
Private access-controlled area with a more personal/artistic feel.

### Features
- Access code entry portal
- Protected routes + encrypted session cookie
- Framed photo gallery
- Sticky-note style short thoughts
- Long-form journal/blog entries
- Polaroid / scrapbook aesthetic
- Ambient interactive design

### Content Types
- Photos
- Notes
- Journal entries
- Collections
- Music embeds
- Travel logs

### Design Direction
Blend:
- digital scrapbook
- Obsidian vault
- corkboard wall
- film photography
- desktop nostalgia
- handwritten/sticky-note UI elements

### Potential UI Ideas
- draggable sticky notes
- pinned polaroid photos
- hover-reveal journal snippets
- animated tape/paper effects
- hidden clickable easter eggs
- “late night desktop” aesthetic mode

### Technical Notes
- Separate protected route group
- Access-code gate before session creation
- Admin-controlled access code rotation
- Blob storage for photos
- MDX support for journals
- Masonry layout for mixed content
